# Medical Device Procurement, Inventory & Manufacturing Management System | Odoo ERP

## Project Overview

This project demonstrates the configuration of an integrated ERP workflow using Odoo for a hypothetical medical device manufacturing company, MediTech Solutions.

The system connects procurement, inventory management, manufacturing and sales processes through Odoo's standard ERP modules.

The business scenario involves sourcing electronic components, managing inventory, assembling a wearable health-monitoring band and fulfilling customer orders.

## Business Scenario

The hypothetical company assembles a wearable health-monitoring product called the **Ovulish Health Monitoring Band**.

The project demonstrates how ERP workflows can support the movement of components from supplier procurement through manufacturing and final customer delivery.

## Modules Implemented

| Odoo Module | Functionality Demonstrated |
|---|---|
| Purchase | Supplier configuration, RFQs and purchase orders |
| Inventory | Product management, goods receipts, stock monitoring and replenishment rules |
| Manufacturing | Bill of Materials and manufacturing order execution |
| Sales | Customer configuration, quotations and sales order fulfilment |

## Key Implementation Activities

- Configured component and finished-product master data.
- Created supplier and customer records.
- Created and confirmed three purchase orders.
- Processed and validated incoming goods receipts.
- Configured a minimum-maximum inventory replenishment rule.
- Created a Bill of Materials for the wearable health-monitoring band.
- Executed a manufacturing order for five finished units.
- Created and confirmed a customer sales order.
- Processed and validated the corresponding delivery order.
- Performed functional verification of the configured workflows.

## ERP Workflow

**Procurement → Goods Receipt → Inventory Management → Bill of Materials → Manufacturing → Finished Goods Inventory → Sales Order → Delivery**

## Scope and Limitations

This is a functional ERP configuration exercise using hypothetical business entities and illustrative product data. It demonstrates standard Odoo workflows and does not include custom module development, API integration, external system integration, legacy data migration or production deployment.

The Bill of Materials represents a simplified project assumption and is not a validated engineering specification.
